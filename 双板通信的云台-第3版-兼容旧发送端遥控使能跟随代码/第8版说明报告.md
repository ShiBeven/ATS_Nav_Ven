# 第8版：统一导航、云台原工程命名

## 修改目的

用户要求融合后的变量名、函数名和结构体相关名称与 `导航-第2版`、`云台-第2版` 保持一致，避免同一协议在不同工程中出现多套命名。

## 本版统一内容

- `can_send_board_frame` 改为原导航工程的 `CAN_SendRcFrame`。
- 新增的遥控器打包改用原工程已有的 `rc_put_i16_be`。
- `header`、`mailbox` 改为原工程使用的 `board_tx_message`、`send_mail_box`。
- 导航帧发送继续使用原云台工程的 `board_tx_message`、`nav_data`、`nav_send_data`、`Navigation_speed_set`。
- `CAN_SendRcBasic`、`CAN_SendRcAux`、`CAN_SendRcMouse`、`can2_slot` 等名称与导航第2版保持一致。
- 未修改 CAN ID、帧长度、字节序、20 ms 调度和 FreeRTOS 任务。

## 版本保护

第7版目录保留不变。本版目录为：

- Keil ARMCC：0 errors，110 warnings。
