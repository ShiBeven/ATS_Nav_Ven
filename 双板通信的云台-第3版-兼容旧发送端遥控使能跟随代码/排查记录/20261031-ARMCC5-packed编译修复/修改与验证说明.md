# ARMCC5 packed 解包编译修复

日期：2026-10-31。项目：D:\code-ai\新建文件夹 (2)\双板通信的云台。

## 修改范围

用户要求保留原有功能。只修改 application/usb_task.c 中 unified_nav_apply_ats_gcc_54 的字段解包部分。

原来直接将 __packed float/uint16_t 成员地址交给 memcpy，ARMCC V5.06 update 6 build 750 报 6 个 #167 类型错误。现在先复制到普通 float decoded[4] 或 uint16_t checksum 局部变量，再逐字段赋值；mode 增加 (enum mode) 显式转换，仍读取 frame[21]。

结构定义、54 字节帧长度、字段偏移、CRC 校验、stop 语义和模式值保持原样。该函数 nav_last_rx = now 起的控制代码、函数外源码及 usb_task.h 与修改前备份逐字比较一致，因此导航/视觉仲裁、超时、CAN 转发和控制参数保持原样。
