# 恢复旧版视觉 USB 协议

日期：2026-10-29。用户要求恢复成以前的视觉通信，随后明确“就跟之前一样就行”。本轮以当前工程保留的 VisionRecvData_t、Vision_send_t 和旧 usb_send_vision 字段赋值为依据，恢复 USB 视觉入口与回传，不回退整个固件。

## 当前默认行为

- `application/usb_task.h` 保持 `USB_YAW_DEBUG=0`，即正常通信。
- 新增 `USB_LEGACY_VISION_TX=1`，正常模式默认只回传旧版 42 字节视觉包，不混发 49 字节状态包或 AA55 波形包。若未来明确需要统一 ID 0x0E 状态回传，可将该项设为 0 后重编译；本次交付是旧版回传。
- 接收端恢复 `0xA5` 开头的 28 字节视觉指令，并保留现有 `0x5A` 统一协议的 35 字节视觉与 50/52 字节导航接收。
- 原导航速度 CAN2 转发、100 ms 超时处理、导航接管优先级和视觉超时处理保持原样。没有屏蔽超时块，也没有增加“导航超时退无力”的新策略。
- 校准、PID、CAN、IMU/遥控保护源码未修改。没有改视觉组上位机代码，也没有烧录或操作硬件。

## 旧视觉下发：28 字节

| 偏移 | 内容 |
|---|---|
| 0 | `0xA5` |
| 1 | mode，0/1/2 |
| 2～5 | yaw |
| 6～9 | yaw_vel |
| 10～13 | yaw_acc |
| 14～17 | pitch |
| 18～21 | pitch_vel |
| 22～25 | pitch_acc |
| 26～27 | CRC16，低字节先发 |

六个数值为小端 float32。沿用旧 CRC16 算法：初值 0xFFFF、反射多项式 0x8408、无最终异或，校验覆盖前 26 字节。接收时不额外进行角度单位变换；当前控制路径使用弧度角目标，上位机须沿用原单位约定。

USB 收包回调继续只将字节入环形缓冲；任务按字节流解析，支持拆包、粘包和混合帧。只有完整帧、合法 mode、CRC 通过才更新 vision_cmd 和 vision_last_rx；没有导航接管时再更新 ReceivedPacketVision。校验失败逐字节重新寻找帧头，不把 USB 单次接收长度当成协议包长度。

## 旧视觉回传：42 字节

`0x5A + mode + q[4] + yaw + yaw_vel + pitch + pitch_vel + bullet_speed + bullet_count + CRC16`

- header/mode 各 1 字节，q 和其余 float 均为小端 float32，bullet_count 为 2 字节，末尾 CRC16 为 2 字节。
- 与旧函数保持一致：mode 取 Follow_Vision；四元数取 INS_quat；角度和角速度字段按旧函数转换为 deg、deg/s；弹速取裁判系统值、bullet_count 为 0。未调整旧函数的轴索引或控制算法。
- 每至少 5 ms 尝试发送；USB 未配置、类句柄为空或上帧未结束时跳过。独立静态发送缓冲在上一帧完成前不会重写。
- 当前默认不会输出统一 ID 0x0E 的 49 字节回传。导航指令接收和 CAN 转发仍保留；如果导航上位机也依赖 49 字节回传，需按其接口选择回传格式，不能认为 42 字节与 49 字节自动互通。

## 文件与使用

- 修改前备份：`排查记录/20261029-恢复旧视觉USB协议-修改前/`。
- 新 HEX：`usb-legacy-build/OBJ/PROJECT.hex`。
- 新配套 AXF：`usb-legacy-build/OBJ/PROJECT.axf`。
- 独立构建项目：`MDK-ARM/PROJECT-legacy-usb-check.uvprojx`，仅输出目录改为 `../usb-legacy-build/OBJ/`。原项目文件和原 `MDK-ARM/OBJ` 构建产物保留。
- 后续从原 PROJECT.uvprojx 正常重新编译，也会包含本次源码修改。新 HEX 尚未烧录；使用新固件时应加载配套 AXF，不能继续用旧 MAP 的固定地址观察新布局。
- 接通视觉 USB 后，先在双下无力状态检查 ReceivedPacketVision 和限定名的 vision_last_rx。收到旧视觉帧时 head 应为 A5、CRC 字段保留接收到的值、接收时间应持续推进。未进行上位机联调，不能仅凭离线测试宣称实机已经恢复通信。

## 本次复利与踩坑

- 用户偏好：视觉组接口恢复原样，优先在电控端恢复兼容，不要求视觉组迁移到后来新增的帧格式。
- 不能将“关闭波形模式”当作“恢复旧视觉协议”；真实运行路径的帧头、长度、字段、单位与 CRC 必须一并核对。
- 恢复旧协议时应保留任务式收包和异步发送缓冲生命周期，不能重新把 USB 单次回调长度当成完整帧，也不能主动调用 CDC_Receive_FS 假装读取数据。
