# 进入导航时蜂鸣器响一次

日期：2026-10-24。工程：`D:\code-ai\双板通信的云台`。

## 实现

- 修改 `application/gimbal_task.c`，增加 `bsp_buzzer.h`、提示音参数和 `gimbal_navigation_beep_update()`。
- 本工程导航是 `GIMBAL_VISION`（7），由 `Gimbal_Vision()` 执行；`AUTO_AIM`（8）为自瞄，不作为本次触发条件。
- 在云台主循环完成模式选择、反馈更新和故障锁存门控后调用。实际模式从非导航变成导航时，只调用一次 `buzzer_on(31, 20000)`，默认持续约 150 ms。
- 使用 `HAL_GetTick()` 和无符号时间差计时，不新增 `HAL_Delay()`、`osDelay()` 或 `vTaskDelay()`。实际停止时刻为达到 150 ms 后的首个云台循环。
- 一直保持导航不重复响；退出并重新进入会再响一次。未到时退出导航或故障退无力，下一次更新立即关闭本次提示音。
- 仅在本函数启动的提示音尚未结束时执行关闭，平时不反复调用 `buzzer_off()`。沿用原有蜂鸣器驱动及硬件初始化，不引入新的全局蜂鸣器仲裁层。

参数在文件开头：`GIMBAL_NAV_BEEP_TIME_MS=150U`、`GIMBAL_NAV_BEEP_PSC=31U`、`GIMBAL_NAV_BEEP_PWM=20000U`。时长可按需要改成 `100U` 或 `200U`。PSC/PWM沿用工程已有云台提示音参数，实际听感需要板上确认。

这是云台模式进入提示，不代表导航数据在线、底盘已接管或导航已成功运行。原有校准、INIT、故障锁存及导航进入条件继续生效；被保护挡住时不触发导航提示音。
