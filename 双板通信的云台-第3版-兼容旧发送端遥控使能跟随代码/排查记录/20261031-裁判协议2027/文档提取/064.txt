2.2.13  RobotPosition  
用途：机器人空间坐标和朝向。 
数据编号 数据类型 数据用途 
1 float 世界坐标 X 轴 
2 float 世界坐标 Y 轴 
3 float 世界坐标 Z 轴 
4 float 本机器人测速模块的朝向，单位：度，正北为 0 度 
5 uint32 
接收到的坐标归属机器人，7/107 为哨兵机器人（仅指挥手客户
端生效） 
message  RobotPosition {  
  optional  float x = 1;  
  optional  float y = 2; 
  optional  float z = 3;  
  optional  float yaw = 4;  
  optional  uint32 robot _id = 5; 
}

数据编号 数据类型 数据用途 
1 uint32 机器人 ID

x 表示热量冷却增加 x/s，增益值若非整数则按四舍五入原
