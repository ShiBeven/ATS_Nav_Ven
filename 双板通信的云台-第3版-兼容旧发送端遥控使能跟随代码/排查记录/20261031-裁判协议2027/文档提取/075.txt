2.2.32  Sentry CtrlResult  
用途：哨兵控制指令结果反馈。 
数据编号 数据类型 数据用途 
1 uint32 对应的指令编号 
2 uint32 执行结果码 
result_code 枚举值： 
 0：成功 
 其他：失败 
message  Sentry CtrlResult {  
  optional uint 32 command_id = 1;  
  optional uint 32 result_code = 2;  
}
