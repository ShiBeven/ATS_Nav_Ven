2.2.28  SentryStatus Sync 
用途：哨兵姿态相关信息。 
数据编号 数据类型 数据用途 
1 uint32 姿态 ID（1 为进攻姿态，2 为防御姿态，3 为移动姿态） 
2 bool 是否弱化 
3 bool 是否强化 
message  Sentry StatusSync { 
  optional  uint32 posture_id = 1;  
  optional  bool is_weakened = 2;  
optional bool is_powered  = 3; 
}
