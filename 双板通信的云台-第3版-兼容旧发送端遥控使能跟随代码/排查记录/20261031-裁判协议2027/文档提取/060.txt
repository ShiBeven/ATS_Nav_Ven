2.2.9  RobotRespawnStatus  
用途：机器人复活状态同步。 
数据编号 数据类型 数据用途 
1 bool 是否处于待复活状态 
2 uint32 复活所需总读条 
3 uint32 当前复活读条进度 
4 bool 是否可以免费复活 
5 uint32 花费金币复活所需金币数 
6 bool 是否允许花费金币复活 
message  RobotRespawnStatus {  
  optional  bool is_pending_respawn = 1;  
  optional  uint32 total_respawn_progress = 2;  
  optional  uint32 current_respawn_progress = 3;  
  optional  bool can_free_respawn = 4;  
  optional  uint32 g old_cost_for_respawn = 5;  
  optional  bool can_pay_for_respawn = 6;  
} 
2.2.10  RobotStaticStatus  
用途：机器人固定属性和配置。 
数据编号 数据类型 数据用途 
1 uint32 连接状态（0=未连接，1=已连接） 
2 uint32 上场状态（0=已上场，1=未上场） 
3 uint32 存活状态（0=未知，1=存活，2=战亡） 
4 uint32 机器人编号 
5 uint32 机器人类型 
6 uint32 性能体系-发射机构
