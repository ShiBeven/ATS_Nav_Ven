# 原路径的小 Yaw 校准修改与操作说明

此前 Watch 已确认：`gimbal_behaviour=2(GIMBAL_CALI)`、`step=0`、`yaw_can_set_current=0xE0C0(-8000)`。原流程结算回0后仍停在CALI、复用反向命令，是本次需要消除的故障。

## 修改结果

- step1、2：Pitch 找两侧机械端点。用户已确认连杆装好，电机能带动枪管及C板。
- step3、4：小 Yaw 找两侧机械端点；大 Yaw 始终零命令，可能因反作用机械随动。
- step5：三轴立即零输出，等待校验和保存。结算回step0后退出CALI。
- 小Yaw用自身CAN转速和编码器稳定情况判停，避免受大Yaw反作用影响的C板绝对角速度误判。Pitch还要求C板对应角速度绝对值小于0.1rad/s。
- 低速判停连续约2秒；运动重置计时，每阶段最多12秒。反馈超过50ms或通信故障时停止；按用户要求已移除校准阶段20RPM超速中止。
- 双拨杆须一直下位；任一离开下位或Watch写`gimbal_cali_abort=1`会中止并保持零输出。机械危险直接切断电机动力，不能靠暂停/断点或手挡。
- 默认Pitch校准命令8000、小Yaw8000，单位是CAN命令值，不是安培。低输出不保证能克服摩擦或对机构安全；静止也不证明已触及限位。
- 计算小Yaw实际反向行程与中点，处理编码器跨零；两侧各留0.1rad余量。拒绝无效行程、方向/上下限错误和明显不符合原角度模型的Pitch结果。Pitch连杆若有明显非线性传动比，需要另行建立角度映射。
- 小Yaw新零位与上下限保存后可重载，不再被1118/±1rad无条件覆盖。大Yaw保留原独立参考7773，其机械对应方向需另行核对。
- Flash布局大小不变，yaw字段改为小Yaw参数；标识`G2P`与旧参数隔离。首次无有效新参数时普通控制零输出，不自动进行电机校准。
- 只更改5个原有源/头文件：gimbal_task.c/.h、CAN_receive.c/.h、calibrate_task.c。CAN增加反馈时间戳及一致性快照，三轴发送使用独立完整报文保护提交；总线、ID、各轴命令字节位置不变，其余字节清零。

普通PID/跟随参数、遥控入口、USB数据格式沿用修改前原工程；本次没有完成手动/视觉模式的完整机械软限位，也不代表此前正常控制失控已解决。

## 操作

1. 保持电机动力断开。若Keil提示源文件被外部修改，重新加载这些文件，避免旧编辑内容覆盖本次修改。
2. 使用当前目录的`MDK-ARM/PROJECT.uvprojx`，目标PROJECT，全量编译并下载。调试符号与下载固件必须来自同一次构建，下载后复位、Run；不要混用其他工程AXF。
3. 双拨杆下位，DM外置陀螺仪、C板陀螺仪与接在合一云台C板上的遥控接收机均正常（当前没有独立导航板）。首次使用新参数预期`gimbal_cali_status=0, gimbal_cali_valid=0`，普通输出为零。
4. 可靠机械限位和支撑条件下恢复动力，沿用两段校准手势：首段ch0负/ch1负/ch2正/ch3负，各幅值超600保持约2秒；次段ch0正/ch1正/ch2负/ch3正保持约2秒。触发后摇杆回中，双拨杆始终下位。
5. 确认Pitch1→2、小Yaw3→4，大Yaw发送命令始终为0。不要用手挡轴测试。
6. 成功后应为`status=2,error=0,valid=1,step=0`；双拨杆保持下位，三轴为零。检查两轴`min_relative_angle<0<max_relative_angle`。
7. 等待至少约2秒，再在电机动力断开的情况下做控制板掉电重载验证：应`status=4,valid=1`，小Yaw零位与刚才一致。
