# 当前原工程三轴监测

当前工程D:/code-ai/双板通信的云台。保留小Yaw限位校准、故障锁存、Pitch初始化目标同步及用户已授权移除20RPM中止的改动；本次只增加监测，控制参数未变。

USB从原6路Yaw改为20路三轴，100Hz、float32小端，帧头AA55、80字节数据、帧尾0D0A，共84字节。请使用同目录SerialPlotter-当前三轴20通道.json，旧6路配置不适用。USB调试模式本来就是1，接收网页发来的字节仍不作为控制命令。

每轮控制完成命令映射后发布一份快照，USB读取已发布快照，避免读取半轮更新的目标和旧命令。指令通道记录软件CAN待发送值，不能证明总线上实际报文已发出。

## 操作

1. 已剧烈抖动时先切断电机动力。下载本工程新固件后复位，确保Keil使用本次AXF。
2. 在原串口绘图网页导入SerialPlotter-当前三轴20通道.json，连接云台C板USB虚拟串口。沿用原串口连接参数，USB CDC的波特率不决定实际100Hz采样率。
3. 先保持双拨杆下位、摇杆回中，在无力状态且反馈传感器有供电时，小幅手动抬/低Pitch。确认三轴软件命令为0，记录Pitch相对实际角和INS绝对实际角是否同向连续变化。不要用手挡住有输出的电机。
4. 优先提供上述无力反馈记录及已有异常记录；不要为了采集继续让机构剧烈抖动或碰撞。若具备可靠限位/支撑和断动力条件，再只记录短暂进入INIT的过程，出现强抖立即断动力。
5. 导出CSV；保持20列通道顺序。CSV内相对目标角只在模式1的初始化阶段解释为当前角度环目标，进入模式3后它们可能是旧值。
