# Pitch 上限位反向抖动检查（2026-10-22）

用户描述：左中右中，向上推摇杆到最高机械限位，随后反向向下，Pitch剧烈抖动。单向慢移已解决。本轮为只读诊断，没有修改控制代码、重编译、烧录或操作硬件。

## 已确认的源码行为

1. 左中右中从无力先经INIT，正常结束后进入ABS（3）。应按发生时模式区分，不能把后续手动反向归为初始化。
2. ABS中目标=rad_format(旧目标+通道3*-0.000002)，随后每周期夹到min/max_relative_angle。若有限且有序的范围为[-0.4,0.6]，向上长期推只能令目标保持0.6，反向增量-0.001立即得到0.599。因此不能声称ABS一定存在无界目标累加；Pitch正常内外环Ki也都是0，传统积分饱和不是目前证据支持的主因。
3. 该限幅夹的是IMU绝对目标，所用范围来自编码器相对角。校准通过直接驱动近似模型尝试对齐二者，但该等价需要验证，连杆非线性、参考误差或机身姿态变化可破坏等价。若范围正确且余量足够，正常运动应在硬限位前停止；仍撞硬限位是需要核对的事实。
4. 校准已有0.1rad内缩，不能声称完全没有余量，也不能未看实测就再任意扩大。
5. gimbal_PID_calc的Dout=kd*error_delta，传入的error_delta是正向实测gyro，而不是误差导数。正常Pitch外环Kp28/Kd+0.5，内环Kp8500，故忽略内环D与饱和时u≈8500*(28*角误差-0.5*实测角速度)。这仍有制动，但比外环D=0时制动少一半，不能称整个环路必为正反馈。固定目标下，若gyro与角度变化同向，负号实测速度项才会增加阻尼；需限定Pitch调用，不应盲改所有Yaw/视觉共享函数。
6. 历史CSV1792665707573的平稳运动段10~18.5秒，用100ms角度差分与11点平均gyro核对，281个abs(rate)在0.02~1.5rad/s的点拟合约rate=1.00368*gyro+0.00301，相关0.999857。支持当时Pitch角速度与角度导数同向。它不是新上限位反向故障的实测记录，不能替代当前波形。
7. 源码另有INIT相对目标无限幅累加，仍需修正，但不能把它当成本次ABS反向的直接证据。

## 现有证据限制与下一步

上一张Watch是status3/error4/error_step2/valid0，按当前源代码此状态不能进入正常ABS。现描述可能发生在之前、重启加载旧记录后或另一固件/修改后的状态。须读取当前有效参数，不能把两种状态当同一时刻。

已询问：valid/status；Pitch max_relative_angle/min_relative_angle/absolute_angle/absolute_angle_set/relative_angle；反推后是已经离开上限位再抖，还是仍在限位附近抖。

- 目标反向后仍在实际端点之外：先处理可达范围、角度参考、软限位和目标跟踪受阻；远端目标会让摇杆反向后暂时仍保持同向推力。
- 目标已进入可达范围但离开端点后指令反复变号、速度交替增大：更支持碰撞释放后闭环欠阻尼/连杆弹性和间隙，应在安全中间行程验证，并针对Pitch核对D方向、调整增益及速度限制。
- 电机编码器已动但枪管/INS不动或局部运动方向反转：优先检查连杆死点、卡滞、松动，不用PID掩盖传动失效。

不要为取证反复强顶硬限位。已有20路的第3路是INIT相对目标，ABS下可能为旧值，不能把它当绝对目标；当前绝对目标需Watch读取，或之后明确改监测协议再采集。
