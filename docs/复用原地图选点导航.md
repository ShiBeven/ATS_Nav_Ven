# 复用原地图选点导航

不建图、不启动重定位，直接使用 `rmul` 原地图。

## 1. 环境

```bash
source /opt/ros/humble/setup.bash
source ~/ATS/install/setup.bash
cd ~/ATS
```

## 2. 启动串口

```bash
ros2 launch standard_robot_pp_ros2 standard_robot_pp_ros2.launch.py
```

## 3. 启动导航

```bash
ros2 launch pb2025_nav_bringup rm_navigation_reality_launch.py \
  world:=rmul slam:=False use_relocalization:=False use_rviz:=True
```

## 4. RViz 选点

1. 手放急停。
2. 点击 `Nav2 Goal`。
3. 在原地图上点击目标点并拖出朝向。
4. 松开鼠标发送目标。

不要使用 `2D Pose Estimate`。

车辆启动位置必须与原地图坐标原点对应。
